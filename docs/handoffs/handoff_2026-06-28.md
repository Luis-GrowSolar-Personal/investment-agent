## What was built this session

### 1. Advisory Feed — User Actions column
**File:** `client/src/pages/AdvisoryFeed.jsx`
**Route:** `GET /api/radar/decisions` (added to `server/routes/radar.js`)

The Commentary tab now has a 7th column: **User Actions**. When a ticker is expanded, call rows and decision rows are interleaved chronologically (newest first). Decision rows show:
- Date (`decidedAt`)
- Empty per-call / trajectory / final columns
- User Actions: action badge (ACCEPTED/DECLINED/DEFERRED, color-coded) + move type + owner + reason in italic
- Distinct visual: dark background `#0c0e18`, left border `#1e3a5f`

The `/api/radar/decisions` endpoint returns all `OwnerDecision` rows across all owners with symbol resolved via ticker join.

### 2. Price capture at decision time
**Files:** `server/routes/moves.js`, `client/src/pages/PortfolioManager.jsx`

Every move card decision (accept or decline) now stamps `pricePerShare` into `systemSnapshot`:

```json
{
  "thesisHealth": "Weakening",
  "trajectory": "deteriorating",
  "ratchetTranche": 0,
  "currentPct": 85.32,
  "dollarAmount": 11938.22,
  "pricePerShare": 0.6499
}
```

**Where price comes from:** `lastPrice` on Position rows (populated by Schwab sync). Added to:
- `makeTrimMove` return object
- `makeAddMove` return object
- EXIT inline builder (destructures `price: exitPrice` from `positionMetrics`)

**Decisions before 2026-06-28 do not have pricePerShare.** Confirmed working: decision id=4 (SPWR TRIM_CAP declined at $0.6499).

### 3. Track Record tab
**New file:** `client/src/pages/DecisionAnalytics.jsx`
**Route:** `/track-record`
**Wired into:** `InvestmentIdeas.jsx` (4th tab), `App.jsx` (IDEAS_PATHS includes `/track-record`)

**What renders today:**
- Bias summary bar: total decisions, trim avoidance %, add acceptance %, top decline reasons (frequency-ranked)
- Per-ticker expandable groups sorted by most recent decision
- "ALL PASSED" badge on tickers where every logged decision was a pass
- Decision rows: date, move type badge, decision badge, $ recommended, price at decision, current price (placeholder "—"), Δ (placeholder "awaiting price feed"), context snapshot, decline reason

**What doesn't render yet:**
- Current price (Δ column is all "—")
- Price timeline narrative ("declined at $24 → $20 → $16")
- P&L outcome attribution

Full backlog and architecture captured in `docs/architecture/TRACK_RECORD_SPEC.md`.
